# CSV仕様

まず設定画面の「CSVテンプレートを保存」を利用してください。
文字コードはUTF-8（BOMあり／なし）、Shift_JIS、UTF-16LEに対応します。
自動判定で文字が正しく読めない場合は、取り込み前に文字コードを指定してください。
書き出しはUTF-8 BOM付き、CRLF改行、全セル引用符付きです。
改行・カンマ・引用符を含む文章も扱えます。

## 列

| 列 | 値 |
| --- | --- |
| rowType | `collection` / `category` / `question`。省略時はquestion |
| id | 問題ID。空欄なら新しく自動作成 |
| collectionId | 所属問題集の固有ID。必須 |
| collectionName | 新しい問題集の場合に必須。既存IDなら元の名前と一致させる |
| categoryId | 分類ID。分類なしは空欄 |
| categoryName | 新規分類の場合に必須 |
| questionType | `trueFalse` / `multipleChoice` |
| questionText | 問題文。必須 |
| choices | JSON文字列配列。例 `["東京","大阪"]`。CSV内の引用符は2つにする |
| correctAnswer | ○×は`true` / `false`。選択式は0始まりの番号 |
| explanation | 解説。省略可 |
| status | `unset` / `review` / `unsure` / `learned`。省略時はunset |
| statusUpdatedAt | ISO形式日時。未設定なら空欄 |
| createdAt | ISO形式日時。空欄なら取り込み日時 |
| updatedAt | ISO形式日時。空欄なら取り込み日時 |

`collection`行は問題が0件の問題集も保存するための行です。
`category`行は問題が0件の分類も保存するための行です。
これらの行では問題に関する列は空欄にします。
必須ヘッダーとして `questionText` はメタデータのみの場合も残してください。

## 既存データの保護

- すべての行を検証し、1行でも不正なら何も取り込みません
- 全件検証後に追加件数を表示し、確認してから保存します
- 同じCSV内または既存の問題に重複IDがあれば取り込みを中止します
- 同一問題集ID・分類IDの名前や所属が既存データと異なる場合も拒否します
- 同名の問題集・分類が別IDで存在する場合は、既存IDを使ってください
- 再取り込みで既存の問題を更新する機能はありません
- 既存の問題集・分類に、新しいIDの問題を追加することはできます
- 空の問題IDを使って何度も取り込むと、その都度別問題として追加されます
- 確認中にデータが変わっていれば保存前に再検証します
- 保存は1トランザクションです。途中で失敗した行だけが残ることはありません

## バックアップとして使う場合

CSVは問題・分類・問題集と問題のステータス・日時を持ち運べます。
空の端末または空のアプリへ取り込んで復元できます。
既存データとIDが重複する場合はそのまま追加できません。
問題集のカバー色などの表示設定はCSVに含めません。
CSVのセルが数式として解釈される表計算ソフトでは、信頼できないCSVを開く際に
セル型を文字列に指定してください。
